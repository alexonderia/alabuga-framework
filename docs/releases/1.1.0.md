# Alabuga Framework 1.1.0 — выпуск

Версия опубликована 22 октября 2026 в авторизованном локальном Verdaccio
`http://127.0.0.1:4873/`, тег `latest`. Ручная проверка со скринридером отложена
по явному решению пользователя; результат проверки не заявляется.

Формат AFDocument, поддержка
документов 1–3, существующие DOM-хуки и подключение готовых JS/CSS сохранены.
Новые компоненты и необязательные возможности API соответствуют minor-версии.

## Что вошло

- Фирменный Select/List/ListItem с клавиатурой, формами, S/M/L и cleanup.
- Calendar с подтверждением и диапазоном, DatePicker S/M/L с нативным значением формы.
- Состояния кнопок, icon-button, checkbox/radio/Switch, Field и Textarea.
- Типографика, фирменные списки, поверхности, Option-btn/Multi-switch,
  Chip/Alert, слоты Dialog и навигация.
- Каталог доступных иконок и локальный архив источников Figma с проверкой целостности.

В текстовых документах renderer явно применяет `af-link--inline` и
`af-alert--accessible`. Эти модификаторы сохраняют читаемые роли и полную высоту строки.
Матрицы компонентов показывают исходную палитру Figma. Замечание о контрасте исходной
палитры относится к ней самой и не отменяет проверку доступности остальных интерфейсов.

## Воспроизводимая подготовка

1. `npm run build:docs`, `npm run check:docs`, `npm run check:design`, `npm test`.
2. Полный Playwright-прогон трёх движков с JSON-результатом
   `artifacts/release-1.1.0/browser-final.json`. Отчёт содержит `frameworkVersion=1.1.0`.
3. Канонический пакет собирается на Linux с Node.js 24.19.0 / npm 11.17.0,
   как в `tests/Dockerfile.package`. Все публичные файлы, exports и integrity проверяются.
4. `npm run test:consumers` устанавливает именно проверенный архив и подтверждает
   Node без DOM, TypeScript NodeNext и React StrictMode.
5. `npm run prepare:release` сверяет пакет, версию, integrity и полный результат тестов,
   повторяет быстрые проверки и формирует локальную страницу и файлы кандидата.

Команда подготовки не публикует пакет, не создаёт тег и не обновляет Constructor.
Пакет, JS/CSS, автономные примеры, контрольные суммы и результаты находятся в
`artifacts/release-1.1.0/`. Копия страницы просмотра — `dist/docs/releases/1.1.0/`.

## Ограничения исходников

В архиве есть инвентаризация всех 23 семейств, но не все подробные контексты и SVG.
Help, CancelRound, Check, Radio и Default не подменены другими рисунками. Previous/Next
масштабируют исходный SVG 20 px, Calendar/Close — 24 px. Все такие расширения перечислены
в `design/icon-catalog.json`. Оригинальные байты некоторых пользовательских скриншотов
отсутствуют локально; пиксельное сравнение с ними не заявляется.

## Результат автоматической приёмки

Полный прогон: **280 пройдено, 8 штатно пропущено, 0 ошибок и 0 flaky** в Chromium,
Firefox и WebKit. Пропуски относятся к дублирующим Chromium-снимкам и неподдерживаемой
эмуляции forced colors в WebKit. 16 unit-тестов, типы, токены, границы, локальный
архив и RU/EN-документация прошли. Linux-пакет содержит 134 файла и собран с
Node.js 24.19.0 / npm 11.17.0. Установка в изолированные Node/TypeScript/React
окружения проверена. Сохранены PDF, 11 снимков слайдов и страницы на трёх ширинах.
Дополнительно записаны семь автоматических снимков дерева доступности.

Проверены чтение под учётной записью потребителя, установка с пустым npm-кешем,
импорт всех ESM-точек без DOM и совпадение JS/CSS с проверенной сборкой.
Подтверждение: `artifacts/release-1.1.0/publication.json`.

```sh
npm install --save-exact @alabuga/framework@1.1.0 --registry=http://127.0.0.1:4873/
```

Нужна настроенная учётная запись чтения реестра. Внешний production-реестр и
GitHub Release в этот выпуск не входят. Обновление внешних потребителей выполняется
отдельно точной версией и lock-файлом. README внутри неизменяемого npm-архива
содержит статус на момент сборки; актуальные сведения о публикации находятся здесь.
