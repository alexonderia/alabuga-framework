# Alabuga Framework 1.3.1 — кандидат выпуска

Описание относится к версии `1.3.1` из `package.json` и `package-lock.json`.
Подготовка формирует локальные материалы приёмки; публикация выполняется отдельно.

## Изменения после 1.1.0

- Независимые размеры блоков для планшета и телефона через `widget.responsive`:
  ширина 1–100% строки и минимальная высота 0–3200 CSS px. Порядок блоков
  задаётся `tabletOrder` и `mobileOrder`; DOM соответствует визуальному порядку.
- Подпись и номер слайда через `page.chrome`. Поддержаны видимость, текст,
  форматы `padded`, `plain`, `total` и положение номера `left`, `center`, `right`.
  Для изолированных миниатюр доступны `slideOffset` и `slideCount`.
- Независимые фон и цвет номера через `page.chrome.number.background` и
  `page.chrome.number.color`. Фон: `transparent`, `white`, `ink`, `blue`, `light`;
  текст: `inherit`, `ink`, `blue`, `white`, `muted`. Непрозрачный фон получает
  отступы 2×8 px. Настройки сохраняются при смене композиции и экспорте.
- Живой справочник и RU/EN-руководства используют шрифты и компоненты Framework,
  сгруппированную навигацию, оглавления и адаптацию к узким экранам.
- В примере рабочей панели карточки и таблица растут по содержимому.
  Автоматическая минимальная высота устраняет переполнение в WebKit после
  изменения ширины; проверяются сужение и обратное расширение панели.
- Эталонные скриншоты компонентов обновлены для Linux/Chromium. Проверка Alert
  различает минимальную высоту и рост многострочного текста, проверяя отсутствие
  обрезки и горизонтального переполнения.
- Добавлено описание текущего выпуска. `check:docs` проверяет его наличие и
  непустое содержимое до браузерного прогона и подготовки кандидата.

## Совместимость

Подключение готовых JS/CSS, существующие точки входа и DOM-опоры сохранены.
Документы без новых полей сохраняют прежнее оформление и нормализацию схемы.
`responsive` требует схему 4, `chrome` — схему 5; документы с настройками цвета
номера следует открывать в Framework 1.3.1 или новее. Формат оболочки Constructor
и его выпуск управляются отдельно.

Размеры Alert S/M/L задают минимальную высоту 32/40/48 px. Перенос текста может
увеличить её; точные переносы зависят от ширины и метрик шрифта браузера.

## Воспроизводимая подготовка

Используйте Linux, Node.js 24.19.0 и npm 11.17.0:

```sh
npm ci
npx playwright install --with-deps
npm run check:design
npm run build
npm test
npm run test:package
npm run test:consumers
npm run build:docs
npm run check:docs
PLAYWRIGHT_JSON_OUTPUT_FILE=artifacts/browser-final.json npm run test:browser -- --workers=1 --reporter=line,json
npm run prepare:release
```

Подготовка сверяет версии, integrity пакета, установленный потребителями JS/CSS
и полный браузерный отчёт Chromium, Firefox и WebKit. Результаты должны относиться
к версии 1.3.1 и содержать все тестовые файлы без ошибок и flaky-результатов.
Контрольные суммы и фактические результаты записываются в `acceptance.json`.

Кандидат сохраняется в `artifacts/release-1.3.1/`, копия страницы приёмки —
в `dist/docs/releases/1.3.1/`. Команда не публикует пакет и не создаёт тег.

## Ручная проверка со скринридером

Ручная проверка NVDA/VoiceOver для 1.3.1 не выполнялась. Автоматические проверки
axe и клавиатурные сценарии не подтверждают фактическую озвучку.

| Сценарий | Ожидаемое поведение |
| --- | --- |
| Select | Название, значение, раскрытое состояние и недоступные пункты; возврат фокуса по Escape |
| DatePicker | Название поля, дата и ошибка; календарь объявлен диалогом; отмена сохраняет значение |
| Calendar | Объявляются месяц и выбранный день; стрелки перемещают фокус, Enter выбирает |
| Option/Multi-switch | Объявляются выбор и disabled |
| Chip/Alert | У действия удаления понятное имя; после удаления фокус сохраняется |
| Dialog | Объявляются заголовок и описание; работают удержание Tab, Escape и возврат фокуса |
| Навигация и иконки | Текущий пункт понятен, декоративные иконки не дублируют название действия |
