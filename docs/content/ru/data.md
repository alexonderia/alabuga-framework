# Схемы документов

AFDocument поддерживает схемы 1, 2, 3 и нормализует их в 3. Framework не сохраняет проекты. asset: разрешается callback потребителя. assetsBaseUrl задаёт адрес встроенных материалов. Экспорт получает CSS/JS и async resolver явно. Браузерное хранилище принадлежит Constructor.
