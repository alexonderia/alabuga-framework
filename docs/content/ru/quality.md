# Проверки и приёмка библиотеки

## Обязательные уровни

Проверяйте типы, границы зависимостей, unit-тесты схем/ресурсов/композиций, все публичные exports и декларации. test:package проверяет состав архива, test:consumers — установку вне workspace, Node без DOM, TypeScript NodeNext и React SSR/StrictMode mount/update/cleanup.

Браузерные проверки охватывают поиск справочника, клавиатуру, формы, диалог, календарь, таблицу, презентации, экспорт, доступность и 50 слайдов/500 элементов с сохранением фокуса и DOM. CSS-состояния используют toHaveScreenshot для default, disabled, selected, hover, focus и pressed. Простое сохранение снимка не является сравнением.

Playwright запускает отдельный сервер 4277. Для установленного Chrome задайте AF_BROWSER_CHANNEL=chrome и --project=chromium; для всей матрицы установите согласованные Chromium/Firefox/WebKit через npx playwright install. Не используйте рабочий сервер приложения вместо тестового.

## Ресурсы и доказательства

Проверьте нестандартный assetsBaseUrl, старые пути /assets, data/asset: и сетевые изображения. Сайт и презентация должны открываться из экспортированного HTML с отключённой сетью с прежним ограничением внешних HTTP(S)-изображений. PDF с фонами проверяется отдельно. Доказательства генерируются заново; модели и весь каталог артефактов не коммитятся.

## Приёмка 1.1.0

Полная текущая матрица проверяет Chromium, Firefox и WebKit, включая автономные HTML, экспорт, формы и компоненты. Результаты JSON, PDF и снимки сохраняются в отчёте кандидата. Проверка архива Figma выполняется без сети через `npm run check:design`; CI также запускает её перед сборкой.

Исходная палитра в каталогах Feedback/Navigation имеет документированные ограничения контраста. Полный тест допускает только точные исходные цвета внутри этих примеров, затем проверяет варианты `--accessible` без исключений. Остальные разделы, renderer и демонстрационные формы проверяются строго. Это не подтверждение AA для исходной палитры и не ручная проверка со скринридером.

Версия опубликована в локальном Verdaccio; новая установка и integrity проверены. Ручная проверка со скринридером отложена пользователем и не выполнялась. Источники, ограничения и сохранённые ручные сценарии описаны в `docs/releases/1.1.0.md`. [Выпуск](/index.html#changes/release-1-1-0).

## Исторический статус

Локальная приёмка разделения ранее зафиксировала 16 unit Framework и 15 Chromium-сценариев, чистых потребителей, визуальные эталоны и воспроизводимый Linux-архив. Общий набор двух проектов — 62 unit и 90 Chromium. Это историческая запись разделения; актуальная матрица трёх браузеров описана выше. Облачные workflows в этом локальном проходе не запускались. GPU и авторские исследования относятся к Constructor и не выдаются за проверки библиотеки. Исторические отчёты прежнего монорепозитория сохранены в Constructor docs/refactor-report.*.md.
