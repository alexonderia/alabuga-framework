# Рефакторинг Alabuga Framework — отчёт приёмки

Дата: 7 октября 2026. [English](refactor-report.en.md).

## Изменения

Один приватный монорепозиторий npm workspaces: `packages/framework`, `packages/ai`, `apps/editor`, `apps/ai-server`, `apps/docs`. У каждой части своя сборка; общий lock-файл, TypeScript и проверка границ. Схема документов остаётся версии 3; структура IndexedDB не менялась.

Публичные точки входа библиотеки отделяют схему, отображение, композиции, подбор оформления и экспорт. Схема проверена в Node без DOM. Экспорт получает CSS/JS явно и разрешает ссылки на материалы через адаптер; доступа к IndexedDB в библиотеке нет. Сохранение больше не импортирует экспорт редактора. Генератор получает подбор слайда через GenerationServices, не импортируя интерфейс. Панель ИИ загружается по требованию.

Из управляющего модуля редактора выделены очередь сохранения, экспорт, масштаб и клавиатурные команды. Существующие модули навигации, холста, свойств, хранения и черновиков сохранены. Очередь сериализует записи, не сообщает об успехе до завершения транзакции и не показывает устаревшее завершение записи поверх нового изменения.

Сборка выпуска создаёт `dist/site`, отдельные сборки приложений и четыре автономных примера. Собранный пакет ИИ открывается в Node. Объявления типов библиотеки входят в сборку. Исходный архив до рефакторинга: `artifacts/refactor/source-before.zip`; контрольные суммы: `source-before.json` рядом с ним. Архивы, модели и тяжёлые отчёты не входят в Git.

Полная регрессия включает миграцию, версии, корзину, ошибки записи, кадрирование, отмену, экспорт, 100 проектов и 50 слайдов с 500 элементами. Для тестов использованы отдельные браузерные профили; хранилище автора не очищалось.

Первый прогон после переноса выявил три устаревшие проверки ссылок: в редакторе подписи стали редактируемыми нейтральными элементами, а в экспорте сохранились настоящие ссылки. Исправлен селектор, проверка ссылок в экспорте сохранена. Ещё одна проверка перезагружала WebKit до завершения записи; теперь она ждёт сохранённый результат.

Промежуточные прогоны одновременно с распаковкой образа Ollama не засчитывались: свободная RAM падала ниже 400 МБ, появились тайм-ауты и остановка тестового сервера. Полный успешный прогон выполнен отдельно. Vite исключает артефакты, сборки и локальные модели из наблюдения, а браузерные тесты владеют отдельным сервером на порту 4275 и не используют рабочий сервер автора.

## Docker и модель

Многостадийные образы содержат только собранный сайт или API; модели, исходные PPTX/PDF/TTC и инструменты тестирования в них не включены. Профиль `ai` добавляет Ollama 0.35.0 и одноразовую инициализацию. Модель и digest закреплены в `config/model-lock.json`. Несовпадение блокирует генерацию. Проверки health и readiness разделены.

Подтверждено возобновление реальной загрузки после остановки контейнеров и Docker Desktop: повторный запуск продолжил её с 73% сохранённого слоя. Подмена digest, ошибка загрузки и повторная попытка также проверены отдельным тестовым сервисом. Эти имитации не выдаются за измерение реальной модели.

В нативном режиме реальная проверка новой сборки прошла: после прогрева секция — 6,129 с, слайд — 7,122 с; выполнены правка, применение, повторное открытие и экспорт без сети. Контекст 4096; Ollama подтверждает `size_vram === size`. Измеренный максимум — 2967 MiB из 4096, 177 измерений с интервалом 250 мс. Это измерение Windows/Vulkan, а не доказательство работы контейнера. Артефакты: `artifacts/refactor/native-rehearsal`.

Реальная первоначальная загрузка обнаружила несовместимость изменяемого тега реестра с историческим pin: скачанный digest `0689d44085e0…`, ожидаемый `324d162be6ca…`. Защита заблокировала ИИ. Pin не менялся. Сохранён точный исходный манифест, все четыре файла которого доступны в официальном реестре по SHA-256. Инициализация теперь скачивает именно их, проверяет каждый файл и только затем публикует манифест. Существующая несовпадающая модель не перезаписывается. Для восстановления прерванного файла используется HTTP Range; эта ветка проверена отдельно. Тестовая несовпадающая модель удалена только из созданного при проверке Docker-тома; исходная нативная копия сохранена.

Контейнерная приёмка прошла на Windows с Docker Desktop/WSL2: после прогрева секция — 5,079 с, слайд — 5,562 с. Правка, применение, повторное открытие и автономный HTML подтверждены. Контекст 4096, `size_vram === size`, 100% GPU. Максимальное измеренное потребление — 3059 MiB из 4096 по 346 отсчётам через 250 мс. Первый холодный пробный запрос вместе с загрузкой/прогревом занял 66,56 с, поэтому перед выступлением нужен явный прогрев. Артефакты: `artifacts/refactor/docker-rehearsal`.

Закреплённые файлы докачались после остановки с 35%. После перезапуска Docker повторная инициализация с `AF_MODEL_REGISTRY=http://127.0.0.1:1` завершилась успешно без загрузки: сохранность тома и работа подготовленной установки без реестра подтверждены. Сервис инициализации ограничен 512 MiB RAM и обрабатывает файлы потоком. CLI Docker Desktop на стенде один раз превысил 90-секундный таймаут остановки; после фактической остановки повторный `docker desktop start` восстановил движок и контейнеры без потери данных. Это ограничение управления установленным Docker Desktop, не проверка физического Linux-стенда.

## Документация и GitHub

Руководства RU/EN: обзор, автор, архитектура, разработка, API, эксплуатация, восстановление, качество. Исходники находятся в `apps/docs/content`; после сборки доступны `/docs/ru/start.html` и `/docs/en/start.html`. Интерфейс редактора не переводился. Старый интерактивный справочник сохраняется; новые руководства содержат двуязычный живой пример.

Подготовлены README и CONTRIBUTING на двух языках, шаблоны задач и PR, CI для типов/границ/модульных/браузерных проверок/сборки/Docker, ручной GPU workflow, правила игнорирования, окончания строк и Git LFS для PPTX/PDF/TTC. Локальный Git инициализирован. Удалённый репозиторий и push не выполнялись; имена организации и репозитория пока не определены. Фактических владельцев CODEOWNERS и защиту окружения GPU нужно назначить при создании приватного репозитория.

## Ограничения и откат

Рефакторинг не улучшал содержание модели. Предыдущая оценка свободных запросов — 12/20 пригодных по содержанию; новый набор из 20 запросов и исследование с авторами в этот этап не входят. Автоматические проверки не являются пользовательским исследованием. Отдельный физический Linux/NVIDIA-стенд не проверялся.

Перед сменой адреса приложения скачайте переносимые проекты: IndexedDB принадлежит origin, а не Docker-томам. Основной адрес остаётся `http://127.0.0.1:4176`. Для отката исходников распакуйте резервный архив в отдельную папку и используйте его lock-файл. Для отката контейнеров выберите сохранённые теги образов через AF_WEB_IMAGE/AF_API_IMAGE и выполните `docker compose up -d --no-build web api`, сохраняя адрес и тома. Не применяйте `down -v` для обычного обновления или отката.
