# Архитектура

## Границы пакетов

| Пакет | Ответственность | Зависимости |
| --- | --- | --- |
| framework | Схема, runtime, композиции, оформление, экспорт | Zod; без редактора |
| ai | Контракты, команды, генерация и проверки содержания | Публичные API framework, Zod |
| editor | Витрина, холст, свойства, IndexedDB, интерфейс ИИ | framework, ai |
| ai-server | HTTP, ограничения, Ollama, инициализация модели | Node.js, конфигурация модели |
| docs | Руководства и живые примеры | framework |

Один репозиторий позволяет изменить схему, редактор и тесты в одном PR. Пакеты приватны; публикация в npm не требуется. Переходы между пакетами разрешены только через их публичные exports. Общая конфигурация модели находится вне серверной реализации.

## Документ и отображение

Версия схемы остаётся 3. В документе хранятся секции, элементы, позиции, фон, типографика, действия и анимации. Runtime одинаков для холста, предпросмотра и экспорта. Редактор добавляет управление поверх результата и хранит историю изменений в EditorModel. Импорт схемы не требует DOM или CSS; измерение слайда и отображение требуют браузера.

## Материалы и экспорт

IndexedDB хранит изображения отдельно от структуры документа; ссылки используют `asset:` и устойчивый идентификатор. Адаптер редактора разрешает их перед отображением и экспортом. Библиотечный экспорт также принимает асинхронный `resolveAsset(id)` и явные CSS/JS автономного runtime. Он не обращается к IndexedDB.

Обработка изображений находится в framework; хранилище не импортирует редакторский экспорт. Автономный runtime собирается до потребляющего его приложения через публичные точки входа пакета. CSS, шрифты и сценарий встраиваются в итоговый HTML.

## Генерация

Запрос → структура → заполнение смысловых мест → команды → изолированный черновик → проверки → применение. AIProvider отделяет транспорт от генерации. GenerationServices передаёт браузерный подбор оформления; сам пакет ai не импортирует UI редактора. Проверка геометрии передаётся callback-функцией.

ИИ-панель загружается динамически. Изменения черновика не заменяют текущий проект до применения. Схема проекта не содержит запросы, состояния генерации или служебные отчёты.

## Решения и ограничения

Нет серверной базы проектов, аккаунтов и синхронизации. Docker volume модели не является резервной копией проектов. Сервер ИИ обрабатывает один запрос одновременно. Изменение этих правил требует отдельного архитектурного решения и миграционных тестов, а не скрытого расширения текущего рефакторинга.
