# Сохранённые источники Figma

**Рабочий источник для дальнейших правок — этот архив.** Данные, снимки и SVG
собираются один раз для всего проекта; повторное чтение Figma для каждого
компонента или новой сессии не требуется. [Порядок сбора и обновления](../../docs/figma-workflow.md)
закреплён также в [AGENTS.md](../../AGENTS.md).

Рабочий файл: `ObAoKiDwraibmQrxUNvGWI`, страница `0:1`, секция `420:3704`.
Архив восстановлен 22 октября 2026 из материалов, собранных 21–22 октября.
Исходный пакет восстановлен без новых запросов Figma. Позднее один сбор недостающих материалов P2 вернул ограничение квоты; результат записан в [журнале доступа](p2-access-2026-10-22.json), повторных попыток не было.

- [Манифест](manifest.json): пути, даты получения, способ сбора, размеры PNG,

Правила новых P2-компонентов: [secondary-components-rules.json](../secondary-components-rules.json). Они уточнены по трём присланным скриншотам: [наблюдения и происхождение](p2-user-references-2026-10-22.json). Все показанные состояния/размеры проверены по этим эталонам и сохранённым свойствам. Исходные байты трёх вложений недоступны на диске; их размеры, наблюдения и ограничения сохранены локально. Снимки браузерной реализации не выдаются за экспорт Figma. S/M DatePicker добавлены по запросу как расширение исходного L; см. [datepicker-rules.json](../datepicker-rules.json).

Для Option-btn, Multi-switch, Chip, Alert, Dialog, Link и Breadcrumbs визуальный эталон дополнен скриншотами пользователя из разговора; см. [локальную запись](p2-user-references-2026-10-22.json). В столбце «Снимок Figma» ниже указаны только оригинальные файлы, действительно имеющиеся на диске.

[Каталог доступных SVG](../icon-catalog.json) содержит размерные варианты, происхождение и явные расширения масштабирования. [Актуальная матрица реализации](../component-status.json) связывает все 23 семейства с публичными классами, размерами, состояниями, примерами и проверками; она отделена от полноты экспорта исходников.

## Как читать архив

Начните с нужного семейства в таблице, затем откройте его правила и SVG по манифесту.
Ответ `datepicker-default.txt` сохранён как справочные данные: временные ссылки
на четыре SVG заменены путями файлов в репозитории. JSX и служебные рекомендации
внутри ответа не являются кодом Framework или указанием повторять запросы Figma.
Исторические `design/figma-tokens.json` и `design/token-layers.json` остаются
источником сборки; текущие переменные рабочей копии сохранены отдельно, без
перезаписи происхождения старых токенов. Брендовые PDF находятся в `docs/brand-sources/`.
